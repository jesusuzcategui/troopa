Your AI agent troop in the terminal.

Plan the work, hand each task to a coding agent in its own git worktree, review the diff, ask for changes and merge. Claude Code, Codex, OpenCode, Cursor or Pi, without leaving the keyboard.

The whole flow

From an idea to main, while you do something else

A task becomes a plan step, gets its own worktree and agent, passes its checks and waits for you. Approve it from the terminal or from your phone, and the next step starts by itself.

Everything a task needs, from inbox to main

Board and list

Kanban that scrolls sideways on small terminals, a list grouped by status, foldable statuses, popups and a task panel beside the board.

Agents in worktrees

Move a task to ready and its agent works on a branch in an isolated git worktree. Yolo runs alone; pair opens the agent next to you with TDD.

Review and request changes

See the diff, the checks and a "How to run" summary. Not right yet? Write what should change and the same agent picks it up in the same worktree.

Plans

Chain tasks into a plan. Each step builds on the branch of the one before it, starts by itself when you approve the previous one (or approves itself when its checks pass), and the whole plan merges once.

A second brain

A Markdown vault (Obsidian-friendly) with a note per project, its tasks and how-to-run guides. Troopa keeps it up to date, gives the agent the project context, and lets you browse it with B, or as a graph of notes and links with G.

Hooks and extensions

Get Telegram alerts you can answer, plus a bot with a menu and buttons to start plans, approve steps or add tasks from your phone. Run your scripts on launch, review, approve or merge, and add commands of your own: any troopa-<name> program on the PATH becomes troopa <name>.

And also

  • Merge without leavingApprove, then merge into the base branch with squash or a merge commit. Conflicts abort cleanly. With a remote, Troopa pushes and opens the PR.
  • Comments on the diffMove through the diff, comment any line, and send every comment back to the agent as file:line notes in a new round.
  • Every round, keptEach launch and each request for changes is its own round with your feedback, the agent's summary, checks and log. Older rounds fold away; the latest stays open.
  • Attachments and @filesAttach images, PDFs, code or video to a task, and type @ to reference files from the repo. The agent gets them in its worktree; they never reach your commits.
  • Profiles and accountsTell the agents who they work for (developer, chef, accountant…) and run each project with its own login, like a company subscription next to your personal one.
  • Detects your agentsA first-run setup finds Claude Code, Codex, OpenCode, Cursor and Pi on your computer, and asks before any agent starts.
  • Fifteen themes, two languagesNord, Dracula, Gruvbox, Catppuccin, Tokyo Night and more, or your own TOML. English and Spanish interface.
  • Projects, clients and metricsGroup work by client, filter boards, and compare time, tokens and cost per agent and per project.
  • A CLI for automationEvery action has a versioned JSON command, so scripts and future integrations use the same store as the TUI.

MCP and daemon

  • Register with troopa mcp install claude (or codex, opencode, cursor). Missing clients get the snippet.
  • review_approve needs allow_approve. There is no merge tool.
  • troopa daemon finishes runs and advances plans without the TUI.

How a task moves

  1. inbox

    Capture the task with n; add criteria with e.

  2. ready

    Move it with ]. Troopa creates type/slug, writes TASK.md and asks before launching.

  3. in-progress

    The agent works in its worktree. enter shows the live log.

  4. review

    Read the diff and checks. x sends it back with your notes, y approves.

  5. done

    g merges into main and removes the branch and the worktree.

Install

Linux, macOS and Windows. Needs Git, plus the agent CLIs you want to use.

Downloads the latest release for your system, checks its checksum and puts troopa in ~/.local/bin.

curl -fsSL https://jesusuzcategui.github.io/troopa/install.sh | sh

Each release ships .deb, .rpm, .apk and Arch packages. Download the one for your system from the releases page.

# Debian / Ubuntu
sudo apt install ./troopa_*_linux_amd64.deb
# Fedora / openSUSE
sudo dnf install ./troopa_*_linux_amd64.rpm
# Arch
sudo pacman -U ./troopa_*_linux_amd64.pkg.tar.zst
Latest release →

With Go 1.26 or newer:

go install github.com/jesusuzcategui/troopa/cmd/troopa@latest

Download troopa_<version>_windows_amd64.zip from the latest release, unzip it and add the folder to your PATH. Pair mode needs Windows Terminal or WezTerm.
