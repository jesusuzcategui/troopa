Your AI agent troop in the terminal.

Plan the work, hand each task to a coding agent in its own git worktree, review the diff, ask for changes and merge. Claude Code, Codex, OpenCode, Cursor or Pi, without leaving the keyboard.

Install View the code

Everything a task needs, from inbox to main

Board and list

Kanban that scrolls sideways on small terminals, a list grouped by status, foldable statuses, popups and a task panel beside the board.

Agents in worktrees

Move a task to ready and its agent works on a branch in an isolated git worktree. Yolo runs alone; pair opens the agent next to you with TDD.

Review and request changes

See the diff, the checks and a "How to run" summary. Not right yet? Write what should change and the same agent picks it up in the same worktree.

Merge without leaving

Approve, then merge into the base branch with squash or a merge commit. Conflicts abort cleanly. With a remote, Troopa pushes and opens the PR.

Comments on the diff

Move through the diff, comment any line, and send every comment back to the agent as file:line notes in a new round.

Every round, kept

Each launch and each request for changes is its own round with your feedback, the agent's summary, checks and log. Older rounds fold away; the latest stays open.

Attachments and @files

Attach images, PDFs, code or video to a task, and type @ to reference files from the repo. The agent gets them in its worktree; they never reach your commits.

A second brain

A Markdown vault (Obsidian-friendly) with a note per project, its tasks and how-to-run guides. Troopa keeps it up to date, gives the agent the project context, and lets you browse it with B, or as a graph of notes and links with G.

Plans

Chain tasks into a plan. Each step builds on the branch of the one before it, starts by itself when you approve the previous one, and the whole plan merges once.

Profiles and accounts

Tell the agents who they work for (developer, chef, accountant…) and run each project with its own login, like a company subscription next to your personal one.

Hooks and extensions

Run your scripts on launch, review, approve or merge, and add commands of your own: any troopa-<name> program on the PATH becomes troopa <name>.

Detects your agents

A first-run setup finds Claude Code, Codex, OpenCode, Cursor and Pi on your computer, and asks before any agent starts.

Fifteen themes, two languages

Nord, Dracula, Gruvbox, Catppuccin, Tokyo Night and more, or your own TOML. English and Spanish interface.

Projects, clients and metrics

Group work by client, filter boards, and compare time, tokens and cost per agent and per project.

A CLI for automation

Every action has a versioned JSON command, so scripts and future integrations use the same store as the TUI.

How a task moves

  1. inbox

    Capture the task with n; add criteria with e.

  2. ready

    Move it with ]. Troopa creates type/slug, writes TASK.md and asks before launching.

  3. in-progress

    The agent works in its worktree. enter shows the live log.

  4. review

    Read the diff and checks. x sends it back with your notes, y approves.

  5. done

    g merges into main and removes the branch and the worktree.

Install

Linux, macOS and Windows. Needs Git, plus the agent CLIs you want to use.

Downloads the latest release for your system, checks its checksum and puts troopa in ~/.local/bin.

curl -fsSL https://jesusuzcategui.github.io/troopa/install.sh | sh

Each release ships .deb, .rpm, .apk and Arch packages. Download the one for your system from the releases page.

# Debian / Ubuntu
sudo apt install ./troopa_*_linux_amd64.deb
# Fedora / openSUSE
sudo dnf install ./troopa_*_linux_amd64.rpm
# Arch
sudo pacman -U ./troopa_*_linux_amd64.pkg.tar.zst
Latest release →

With Go 1.26 or newer:

go install github.com/jesusuzcategui/troopa/cmd/troopa@latest

Download troopa_<version>_windows_amd64.zip from the latest release, unzip it and add the folder to your PATH. Pair mode needs Windows Terminal or WezTerm.
